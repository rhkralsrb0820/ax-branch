## What this verifies / does not
- **Verified with real models, through the web page of the packaged build:**
  - goal submission with a file and dragged departments;
  - delegation and contract;
  - department acceptance: unmet → FAIL → bounded rework → met → PASS;
  - same-version reuse;
  - opening the result;
  - saving feedback.
- **Not verified:**
  - the drag gesture by a human hand (synthetic HTML5 drag events in headless Chrome);
  - visual quality;
  - re-plan reuse/discard and the two-failure contract pause with real models;
  - OS-level isolation (not implemented).
