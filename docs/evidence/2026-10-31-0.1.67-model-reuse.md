# 0.1.67: reusable trained models (2026-10-31)

## What it does (axbranch/model_registry.py)
- Register a project's trained text classifier as a package: predict.py + ONLY the files `predict.py --describe` names
  for the trained arm (no training/evaluation data, no Owner inputs or data); hashes, source version, base model,
  stack pins, task, contract, labels.
- Separate states: registered / runnable (isolated smoke run) / evaluated (complete model_compare result) / approved.
- Connect to a project, or to a department (then usable where that department is attached); append-only, restorable.
- 淸月 sees available models (scope, evidence) and may plan `model_uses`; the engine runs each use before production in
  the isolated runner on THIS project's own input; every attempt recorded; changed files, missing stack, wrong format,
  unapproved or unconnected models are blocked; nothing is substituted; predictions reach later stages at ./model_outputs.
