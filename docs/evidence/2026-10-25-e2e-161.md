## Defect found by this E2E (and fixed after it)
- **The step-2 contract failure was a FALSE POSITIVE.** The project ids were values in the attached CSV's
  `project` column, so citing them meant citing this project's own data. The rework then had to drop
  legitimate data from the result.
- **Fix** (after 90bb049): ids that appear in the project's own input files are not "other projects"
  (`Engine._input_project_ids`, `check_output(known_ids=…)`). Tests:
  `test_ids_that_are_values_in_the_projects_own_input_are_not_foreign`, plus a unit case.
- **So the pinned package above does NOT contain this fix.** The final package and regression are recorded
  separately in `docs/devroom/status.json` and the handoff.
